# aksioma-site-build

Собранный сайт aksioma-vent.ru — только то, что видит посетитель (HTML, стили, скрипты, данные каталога).
Исходники и генератор хранятся отдельно.

Функция `site-deploy` в Yandex Cloud скачивает архив этой ветки и выкладывает файлы в хранилище сайта.
Вручную здесь ничего не правится: каждая сборка полностью заменяет содержимое.
